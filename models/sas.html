🎯 CFD Guidance - Scale Adaptive Simulation

✅ When to Use SAS (Critical Applications)

  • Unsteady separated flows - When separation is inherently unsteady
  • Vortex shedding predictions - Capture periodic vortex structures
  • Mixing and combustion - Large-scale mixing structures important
  • Flows with large separation bubbles - Where RANS fails due to unsteadiness
  • Research applications - When understanding unsteady physics is critical
  • Bridge to LES - When LES is too expensive but RANS insufficient
  • Complex turbulent structures - Capture larger turbulent scales
  • Validation studies - Benchmark against experimental unsteady data

⚠️ When to Avoid SAS (Critical Limitations)

  • Steady flow applications - Cannot capture steady solutions, unsteady only
  • Industrial routine analysis - Too expensive for everyday engineering
  • Limited computational resources - Requires significant CPU and memory
  • Preliminary design studies - Overkill for initial conceptual analysis
  • Simple attached flows - RANS sufficient, SAS unnecessary
  • Parametric optimization - Too slow for design space exploration
  • Grid dependency issues - Results depend on grid resolution
  • Convergence challenges - Unsteady nature makes convergence assessment difficult

Setup Tips & Best Practices

  • Grid requirements: LES-quality grids needed, much finer than RANS
  • Time stepping: Small time steps required for temporal accuracy
  • Initialization: Start from converged RANS solution
  • Simulation time: Long simulations needed for statistical convergence
  • Post-processing: Time-averaged results for comparison with experiments
  • Grid adaptation: Monitor resolved vs modeled turbulence scales

📐 SAS Equations - Detailed Analysis

1️⃣ Modified k Equation with SAS Source

\frac{\partial k}{\partial t} + U_j \frac{\partial k}{\partial x_j} =
P_k - \beta^* k \omega + Q_{SAS} + \frac{\partial}{\partial x_j}\left[(\nu + \sigma_k \nu_t)\frac{\partial k}{\partial x_j}\right]

Physical Meaning: k equation with scale-adaptive source term

∂k/∂t + Uⱼ ∂k/∂xⱼ: Unsteady + convection terms

Pk: Standard production by mean shear

-β*kω: Standard dissipation term

QSAS: Scale-adaptive source term (key SAS addition)

Diffusion: Standard k diffusion

2️⃣ SAS Source Term

Q_{SAS} = \max\left[C_{SAS} \frac{k}{\sigma_{\Phi}} \left(\frac{L}{L_{vK}}\right)^2 |\nabla^2 U| - C_2 k \frac{\partial k}{\partial x_j} \frac{\partial \omega}{\partial x_j} \frac{1}{\omega^2}, 0\right]

Physical Meaning: Detects and responds to unresolved scales

CSAS ≈ 2.0: SAS model constant

L/LvK: Ratio of turbulent to von Kármán length scales

|∇²U|: Second derivative of velocity (detects unsteady structures)

Purpose: Reduces eddy viscosity when large scales are under-resolved

3️⃣ Standard ω Equation

\frac{\partial \omega}{\partial t} + U_j \frac{\partial \omega}{\partial x_j} =
\alpha \frac{\omega}{k} P_k - \beta \omega^2 + \frac{\partial}{\partial x_j}\left[(\nu + \sigma_\omega \nu_t)\frac{\partial \omega}{\partial x_j}\right]

Physical Meaning: Standard k-ω equation for ω (no modification)

Note: SAS modification only affects k equation

Purpose: Provides length scale information

4️⃣ Scale Detection Mechanism

L = \sqrt{\frac{k}{\omega}}, \quad L_{vK} = \kappa \sqrt{\frac{1}{2}} \frac{|\nabla^2 U|}{|\nabla \times \nabla \times U|}

Physical Meaning: Compares turbulent and von Kármán length scales

L: Turbulent length scale from k and ω

LvK: von Kármán length scale from velocity gradients

When L > LvK: Turbulence is under-resolved, SAS activates

κ = 0.41: von Kármán constant

💡 Scale-Adaptive Analogy

Think of SAS as a smart camera with automatic focus that can switch between taking close-up detailed photos and wide-angle landscape shots based on what's in the scene.

RANS mode (steady regions): Like using a standard camera setting for static subjects - efficient and adequate for unchanging scenes.

LES-like mode (unsteady regions): Like switching to high-speed burst mode when action is detected - captures rapid changes and movement.

Scale detection (L vs LvK): Like the camera's motion sensor - detects when something interesting is happening that needs higher resolution.

SAS source term (QSAS): Like the camera's automatic scene detection - boosts the "film speed" (reduces eddy viscosity) when fast action is detected.

Grid dependency: Like camera quality - a better camera (finer grid) can capture more detail, but the automatic switching still works with any camera quality.

🚀 SAS Key Features

Automatic Scale Adaptation

Automatically detects when turbulent structures are under-resolved and reduces eddy viscosity to allow large-scale unsteadiness to develop naturally.

Grid-Scale Awareness

Uses local grid scale information to determine what turbulent scales can be resolved vs what needs to be modeled. Adapts behavior based on grid quality.

RANS-LES Bridge

Provides a pathway between RANS and LES - behaves like RANS on coarse grids but approaches LES-like behavior on fine grids in unsteady regions.

⚖️ SAS vs RANS and LES

✅ Advantages over RANS

  • Captures unsteady large scales: Resolves turbulent structures RANS misses
  • Automatic scale detection: No user specification of resolved scales
  • Better separation prediction: Unsteady separation physics captured
  • Improved mixing prediction: Large-scale mixing structures resolved
  • Grid-adaptive behavior: Automatically uses available grid resolution

❌ Disadvantages vs RANS

  • Much higher computational cost: Unsteady simulations required
  • No steady solutions: Cannot provide time-averaged results directly
  • Grid requirements: Needs much finer grids than RANS
  • Time integration: Small time steps and long simulation times
  • Post-processing complexity: Statistical analysis required

🔄 vs LES

Advantage: Lower cost than LES, works on coarser grids. Disadvantage: Less accurate than LES, still has some RANS limitations near walls.
