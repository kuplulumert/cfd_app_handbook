PISO

Pressure-Implicit with Splitting of Operators

🎯 Practical Applications

🌊 Transient Flows
Unsteady simulations, flow oscillations, vortex shedding
🎭 Dynamic Phenomena
Startup transients, valve operations, pulsating flows
🔬 Research Applications
DNS, LES simulations requiring high temporal accuracy
⚡ OpenFOAM Standard
Default transient solver in OpenFOAM ecosystem

⚙️ CFD Guidance

✅ When to Use PISO:

  • Transient simulations - Primary application domain
  • Small time steps - Δt requiring good temporal accuracy
  • Incompressible flows - Optimized for constant density
  • High-quality meshes - Low skewness, good aspect ratios
  • OpenFOAM users - Native implementation available
  • Research accuracy - DNS, LES, high-fidelity simulations

❌ When to Avoid PISO:

  • Steady-state problems - SIMPLE/SIMPLEC more efficient
  • Large time steps - Use PIMPLE for better stability
  • Poor mesh quality - High skewness can cause instability
  • Compressible flows - Density-based solvers preferred
  • Very low Reynolds numbers - Overkill for creeping flows
  • Limited computational resources - Higher memory usage

✅ Advantages

  • Excellent for transient flows
  • High temporal accuracy
  • Multiple pressure corrections
  • No under-relaxation needed for momentum
  • Well-suited for LES and DNS

⚠️ Limitations

  • Higher memory requirements
  • More expensive per time step
  • Sensitive to mesh quality
  • Overkill for steady-state problems
  • Requires smaller time steps

🔢 Algorithm Steps

Step 1: Momentum Predictor
$$\frac{\partial \rho \mathbf{u}}{\partial t} + \nabla \cdot (\rho \mathbf{u} \mathbf{u}) = -\nabla p^n + \nabla \cdot \boldsymbol{\tau} + \rho \mathbf{g}$$

Solve momentum using pressure from previous time step (no under-relaxation)

Step 2: First Pressure Correction
$$\nabla \cdot \left( \frac{1}{a_p} \nabla p'_1 \right) = \frac{1}{\Delta t} \nabla \cdot \mathbf{u}^*$$
$$\mathbf{u}^{**} = \mathbf{u}^* - \frac{\Delta t}{a_p} \nabla p'_1$$

First pressure correction to improve mass conservation

Step 3: Second Pressure Correction
$$\nabla \cdot \left( \frac{1}{a_p} \nabla p'_2 \right) = \frac{1}{\Delta t} \nabla \cdot \mathbf{u}^{**}$$
$$\mathbf{u}^{n+1} = \mathbf{u}^{**} - \frac{\Delta t}{a_p} \nabla p'_2$$

Second correction for enhanced accuracy (optional: more corrections possible)

Step 4: Final Pressure Update
$$p^{n+1} = p^n + p'_1 + p'_2$$

Sum all pressure corrections (typically 2-3 corrections used)

📊 Variables & Parameters

Δt (s)
Time step size - critical for stability and accuracy
p'₁, p'₂ (Pa)
First and second pressure corrections
𝐮*, 𝐮** (m/s)
Intermediate velocity fields after corrections
aₚ (kg/m³/s)
Central coefficient from momentum discretization
n_correctors (-)
Number of pressure corrections (typically 2-3)
CFL (-)
Courant number for stability (CFL < 1 recommended)

🧠 Engineering Analogy

🎯 Quality Control in Manufacturing

PISO is like a multi-stage quality control process in a fast-moving production line:

  • Step 1 (Momentum): "Production line runs at predicted speed" - based on yesterday's pressure
  • Step 2 (1st Correction): "First quality inspector catches major issues" - fixes big pressure errors
  • Step 3 (2nd Correction): "Second inspector fine-tunes" - catches smaller remaining errors
  • Multiple Corrections: Like having multiple quality checkpoints for precision manufacturing

Time-accurate approach: Like ensuring each production batch meets exact timing requirements - more expensive but essential for precision products that change rapidly.

⚙️ Key Features

🔄 Multiple Corrections
2-3 pressure corrections per time step
⏰ Time-Accurate
Optimized for transient flow physics
🚫 No Momentum Under-Relaxation
Velocity equations solved without damping
🎯 High Accuracy
Better temporal resolution than SIMPLE family
🌊 Implicit Time Integration
Stable for moderately large time steps
🔧 OpenFOAM Native
Extensively validated in open-source CFD
